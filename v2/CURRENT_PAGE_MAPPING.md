# Current → upgraded Materials mapping

The project sidebar still points to:

```text
/workspace/projects/[projectId]/materials
```

That route is overwritten by this package with the complete Materials Control Centre.

The import route is:

```text
/workspace/projects/[projectId]/materials/import
```

The import page is project-wide but always requires a selected target tower before importing.

## Main tabs

- Overview
- Search
- Bundles
- Members
- Bolts & Packers
- Missing / Excess
- Movements
- Reservations
- Amendments
- Reconciliation
